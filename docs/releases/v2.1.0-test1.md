# Keenetic Config Manager v2.1.0 Test1

Первый тестовый релиз ветки **2.1**. Главное изменение — обновление WireGuard / AmneziaWG теперь умеет использовать **штатный импортёр KeeneticOS**, а не раскладывать новые ASC-параметры по командам вручную.

> Это **pre-release / Test1**. Рабочий механизм нативного импорта уже проверен на KeeneticOS 5.2 Alpha 11, но перед переводом в стабильный `v2.1.0` желательно дополнительно прогнать весь Config Manager: обновление нескольких профилей, маршруты, бэкапы и повторные запуски.

## Главное в Test1

### Нативный импорт WireGuard / AmneziaWG

Для KeeneticOS 5.2+ Config Manager сначала использует штатную команду:

```text
interface WireguardN wireguard import {url}
```

Программа временно поднимает одноразовый HTTP-сервер в локальной сети, Keenetic забирает **исходный `.conf`** и разбирает его собственным импортёром.

- `.conf` не отправляется в интернет;
- сервер слушает только локальный IPv4-интерфейс до Keenetic;
- URL случайный;
- файл отдаётся один раз;
- временный сервер автоматически закрывается;
- старый по-полевой способ остаётся fallback для систем без native import URL.

### AmneziaWG 3.0 / 3.1

Добавлено распознавание и read-back новых ASC-параметров:

- `HeaderProtectionKey`;
- `ContentPaddingAddition`;
- `RekeyAfterTime`;
- `RekeyTimeout`;
- `RejectAfterTime`;
- `KeepaliveTimeout`;
- `MaxHandshakeAttempts`;
- `RandomTrailers`;
- `DisableCookies`.

Поддерживаются WireGuard, AmneziaWG 2.0 и AmneziaWG 3.x.

### Обновлённый Safe Update

Rollback-база больше **не обязательна** и не блокирует обновление.

Перед изменениями программа по-прежнему автоматически сохраняет:

- `startup-config`;
- `running-config`;
- состояние WireGuard-интерфейса;
- статические маршруты.

`system configuration save` выполняется только после проверки результата импорта и маршрутов.

### UI

- Основная кнопка переименована в **«Обновить конфиг»**.
- Ручные кнопки rollback-базы убраны из основного сценария.
- В интерфейсе отображается `Safety backup: автоматически`.
- Preview распознаёт AWG 3.1 и новые ASC-параметры.

### Исправления

- `last-handshake = 0`, отрицательные значения и служебные значения `>= Int32.MaxValue` больше не считаются успешным handshake.
- Сохранена логика менеджера маршрутов из v2.0.0: Duplicate Skip, пакетная обработка, асинхронная загрузка и safety-бэкапы.

## Проверено

Нативный импорт `.conf` успешно проверен на **KeeneticOS 5.2 Alpha 11** при замене AmneziaWG 3.1 на AmneziaWG 2.0 — сценарий, который не проходил через старую по-полевую запись ASC, но успешно импортировался через веб-интерфейс Keenetic.

## Быстрый старт

1. Скачайте `Keenetic-Config-Manager-v2.1.0-Test1.exe`.
2. Запустите приложение.
3. В **Дополнительные инструменты → Доступ Keenetic** укажите адрес роутера, логин и пароль.
4. Выберите WireGuard / AmneziaWG интерфейс.
5. Выберите новый `.conf`.
6. Нажмите **«Обновить конфиг»**.

Если Windows Firewall впервые спросит сетевой доступ для приложения / Windows PowerShell, для нативного импорта достаточно разрешить доступ в **частной сети**.

## Требования

- Windows 10 / 11 x64;
- Windows PowerShell 5.1;
- локальный доступ ПК к Keenetic;
- права администратора Keenetic;
- для native import — KeeneticOS 5.2+; на более старых версиях используется fallback.
