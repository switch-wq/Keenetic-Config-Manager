# Keenetic Config Manager

**Keenetic Config Manager** — portable Windows-приложение для обновления WireGuard / AmneziaWG-конфигураций и управления статическими маршрутами на роутерах Keenetic.

## Возможности

- WireGuard / AmneziaWG 2.0 / AmneziaWG 3.x `.conf` updater.
- Нативный импорт `.conf` через встроенный импортёр KeeneticOS 5.2+.
- Обновление существующего WireGuard-интерфейса без его удаления.
- Автоматические startup / running / routes safety-бэкапы.
- Read-back проверки после импорта.
- DPAPI-хранение локальных чувствительных данных.
- Просмотр, поиск, добавление и удаление статических маршрутов.
- Массовый импорт BAT / CMD / TXT и IP/CIDR.
- Duplicate Skip и отчёт о количестве повторов.
- Пакетная загрузка больших списков маршрутов.
- Асинхронная загрузка маршрутов и фоновый статус WireGuard.
- Настраиваемый URL Keenetic и credentials.
- Тёмный WPF-интерфейс.
- Portable single EXE.

## Установка

Установка не требуется. Скачайте последний EXE из **Releases** и запустите его.

> Ветка `v2.1.0-test1` распространяется как pre-release для дополнительной проверки перед стабильным `v2.1.0`.

## Первый запуск

1. Откройте **Дополнительные инструменты → Доступ Keenetic**.
2. Укажите адрес роутера, например `http://192.168.1.1:8080/`.
3. Введите логин и пароль администратора Keenetic и нажмите **Сохранить и проверить**.
4. Выберите нужный WireGuard-интерфейс.

## Обновление `.conf`

1. Выберите WireGuard / AmneziaWG интерфейс.
2. Выберите новый `.conf`.
3. Нажмите **«Обновить конфиг»**.

Config Manager создаёт safety-бэкап автоматически. На KeeneticOS 5.2+ исходный `.conf` передаётся штатному импортёру Keenetic через одноразовый локальный HTTP URL. Файл не загружается во внешние сервисы.

Если Windows Firewall впервые запросит доступ, для native import достаточно разрешить приложение в **частной сети**.

## Статические маршруты

Окно **Маршруты** поддерживает одиночные изменения и массовый импорт.

Поддерживаются `.bat`, `.cmd`, `.txt`, `route add/delete`, Keenetic `ip route/no ip route` и простые IP/CIDR списки. Уже существующие и повторяющиеся ADD-маршруты пропускаются автоматически.

## Данные приложения

Рабочие данные и бэкапы хранятся отдельно в `%LOCALAPPDATA%` и не зависят от расположения portable EXE.

## Требования

- Windows 10 / 11 x64
- Windows PowerShell 5.1
- локальный доступ к Keenetic
- права администратора Keenetic
