Keenetic WG & Routes v1.3.4

Запуск:
  Start-Keenetic-WG-Updater.vbs

Если программа не запускается:
  1. Рядом с программой автоматически появится startup-error.log.
  2. Либо запустите Start-Keenetic-WG-Updater-Debug.cmd.

Изменения v1.3.3:
- главное окно показывается до первого сетевого запроса к Keenetic;
- первичный опрос роутера выполняется после показа окна;
- скрытый launcher сохраняет stderr PowerShell в startup-error.log;
- пакетный импорт маршрутов до 950 операций в партии сохранён.


v1.3.3: исправлено отображение таблицы маршрутов в Windows PowerShell 5.1. Маршруты теперь заполняются вручную; удаление/экспорт используют Row.Tag.


v1.3.4: массовый импорт больше не останавливается на уже существующих ADD-маршрутах.
- маршруты, которые уже есть на Keenetic, пропускаются;
- повторные ADD-строки внутри импортируемого файла также пропускаются;
- после импорта показывается общее число повторных маршрутов;
- пакетирование по 950 применяется только к маршрутам, которые реально нужно добавить/изменить.
